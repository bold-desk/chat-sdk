# BoldDesk Chat SDK

The **BoldDesk Chat SDK** empowers you to seamlessly integrate a fully functional chat widget into your mobile applications. With this SDK, end-users can connect with support agents in real time—without needing to open a web browser.

---

## ✨ Highlights
- **Seamless Chat Experience** – Real-time communication with support agents, mirroring the full functionality of the BoldDesk web chat widget.  
- **Custom Themes** – Built-in support for Light, Dark, and System themes for a consistent look and feel.  
- **Font Customization** – Apply your app’s custom fonts to maintain brand identity.  
- **Push Notifications** – Receive instant alerts and updates for new messages.  

---

## 📱 Supported Platforms & Prerequisites

| Platform       | Minimum OS Version | Language   | Version                  |
| -------------- | ------------------ | ---------- | ------------------------ |
| **Android**    | API 28+            | Kotlin     | 2.2+ ([Gradle Compatibility](https://developer.android.com/build/kotlin-support)) |
| **iOS**        | 14.0+              | Swift UI   | 5.3                      |
